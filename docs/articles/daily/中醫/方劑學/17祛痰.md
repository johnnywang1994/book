# 祛痰劑
- 依據痰的性質（寒、熱、燥、濕）進行治療，遵循「燥濕化痰」、「清熱化痰」、「潤肺化痰」等原則
- 專門用來治療因脾虛濕盛、水濕聚而生痰（濕痰）所導致的病證
  - 臨床症狀：咳嗽痰多、痰液色白清稀或黏膩且容易咳出
  - 全身表現：胸悶、腹脹、噁心想吐、頭暈或心悸。
  - 舌脈表現：舌苔白膩或白潤，脈象多滑。
- 主要分為以下四類:


## 燥溼化痰
### 二陳湯
- 治一切痰飲為病，或`嘔吐噁心`(胃內停水)，或`頭眩心悸`，或`中脘不快`，或發為寒熱，或因食生冷，脾胃不和。脈`沈弦細`
- 燥濕和痰，順氣和中。
- 半夏,陳皮,茯苓,甘草
- 陰虛燥痰或痰中帶血者忌用
- 祛痰、鎮咳、鎮吐、抑制胃液分泌、降低胃液酸度、健胃

### 溫膽湯
- 膽胃不和、痰濁內擾證。`虛煩失眠`、`胸悶`有痰，噁心嘔吐、呃逆、或`驚悸不寧`、口苦、苔膩、`脈弦滑`。
- 行氣化痰，調和膽胃。
- 半夏,橘紅,茯苓,甘草,竹茹,枳實,生薑,大棗
- 陰虛血少之眩暈、失眠、心悸等不適用
- `鎮靜安眠`，祛痰鎮咳，止嘔，擴張冠狀動脈，消炎。
- 精神分裂症、憂鬱症、神經官能症、癲癇、冠心病、動脈硬化症、胃炎、膽囊炎、膽石症、慢性支氣管炎、哮喘、甲狀腺機能亢進


## 清熱化痰
### 清肺湯(潤燥化痰)
見清熱藥章節

### 百合固金湯(潤肺化痰)
見清熱藥章節

### 小陷胸湯
- `痰熱互結心下`，胸脘`痞悶`，`按之痛`，或咳`痰黃稠難出`，舌苔黃膩，脈`滑數或浮滑`者。
- 清熱滌痰、開結寬胸。
- 黃連,半夏,瓜蔞實
- 傷寒表證未解，誤治後邪熱內陷，以致痰熱互結，或溫熱之邪氣煎熬津液而成痰。
- 寒證慎用。抗菌，消炎，解熱，利膽，擴張冠狀動脈，抗急性心肌缺血
- 肺炎、支氣管炎、胸膜炎、肋膜炎、胃炎、胃酸過多、膽石症、肺氣腫、心絞痛、胰腺炎、胃神經症
- 大陷胸湯是攻下急救劑(胸口延伸至全腹部)，小陷胸湯是清熱化痰劑(胸口與心窩處)

### 瓜蔞枳實湯
- `痰結咯吐不出`，胸膈作痛，不能轉側，或`痰結胸膈滿悶`，寒熱氣急，并痰迷心竅，不能言語者
- 清熱化痰，理氣止痛
- 瓜蔞,枳實,桔梗,茯苓,貝母,陳皮,山梔,當歸,砂仁,木香,甘草
